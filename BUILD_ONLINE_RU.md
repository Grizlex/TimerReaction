# Сборка APK онлайн бесплатно (GitHub Actions)
1. Создайте бесплатный аккаунт на https://github.com/ .
2. Создайте новый **публичный** репозиторий, например timer-reaction (без README).
3. Откройте репозиторий → Add file → Upload files. Загрузите **содержимое папки TimerReaction** из ZIP, сохраняя структуру, включая скрытую папку .github/workflows. GitHub web upload может не сохранить дерево папок при выборе отдельных файлов: удобнее загрузить распакованную папку целиком с компьютера или воспользоваться Git-клиентом. Альтернативно создайте файлы вручную через Add file → Create new file с путями как в ZIP.
4. Нажмите Commit changes.
5. Перейдите Actions → Build Android APK → Run workflow (или дождитесь автоматической сборки после загрузки в main).
6. После успешной сборки откройте запуск и скачайте TimerReaction-APK в разделе Artifacts.
7. Распакуйте скачанный ZIP, перенесите app-debug.apk на телефон и установите. При необходимости разрешите установку из этого источника.

Важно: проект подготовлен, но в данном окружении APK не компилировался; если сборка выдаст ошибку, сохраните лог и пришлите его в чат.
