# Таймер реакции для Android

Откройте папку TimerReaction в Android Studio (версия с поддержкой AGP 8.7), дождитесь Gradle Sync. Для установки на телефон: Build > Build APK(s), затем установите app-debug.apk. Требуется Android 8.0+.

Одна кнопка ПУСК / СТОП-СБРОС. Отсчёт 0.00–10.00 с с отображением сотых. По умолчанию вибрация за 20 мс до 10 с; ползунок меняет опережение 0–500 мс. Вибрация запускается на главном потоке Android и может запаздывать, точность до 20 мс не гарантируется. APK в архив не включён, так как среда сборки Android недоступна.
